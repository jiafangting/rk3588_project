# UI 界面开发日志

## 技术选型
- 框架：PyQt5
- 运行平台：RK3588 Linux 桌面
- 分辨率适配：1024×600（7寸屏）或全屏

## 界面布局说明

主窗口分为四个主要区域：

1. **顶部状态栏**
   - 左侧显示系统名称
   - 中间显示当前时间
   - 右侧显示系统状态：正常 / 异常 / 报警

2. **左侧摄像头画面区**
   - 显示实时摄像头画面
   - 若视觉模块已启动，则显示处理后的画面或最近一帧结果
   - 若无数据，则显示“摄像头未连接”

3. **右侧传感器和报警区**
   - 上半部分显示传感器数值
   - 下半部分显示最近 5 条报警记录

4. **底部阈值配置区**
   - 可编辑温度、电流、湿度、烟雾等阈值
   - 支持保存配置和恢复默认值

## 数据来源说明

| 数据 | 来源 | 刷新频率 |
|------|------|---------|
| 摄像头画面 | VisionSharedState | 30fps |
| 传感器数值 | alarm_log.csv / UIState 模拟数据 | 500ms |
| 报警记录 | alarm_log.csv | 500ms |
| 阈值配置 | config.json | 启动时/保存后 |

## 遇到的问题与解决

- 数据源可能暂时不可用，所以界面必须支持模拟数据模式，不能因为视觉模块没启动就崩溃。
- 摄像头画面、日志和阈值来源不同，必须统一到 `UIState` 里管理，避免组件之间互相直接读文件。
- 远距离查看时文字不能太小，所以所有字体都按 14px 以上设计。
